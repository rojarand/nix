# AGENTS.md

This project provides configuration for Determinate Nix on macOS.

When working in this repository:

- Treat the Nix flake and related files as macOS Determinate Nix configuration.
- Keep changes focused on Nix, nix-darwin, Home Manager, and supporting macOS setup scripts.
- Prefer small, explicit edits and preserve existing project structure unless a broader change is requested.
